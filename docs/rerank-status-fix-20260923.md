# 重排状态接口与界面联动修复

日期：2026-09-23。

## 原因与修复

`VectorIndex.status()` 原本返回 `reranking`，但 `vector_indexing._status_for()` 的公开字段投影丢弃了它。前端读取不到模型名称和加载状态，两项均显示“未提供”。

- 状态接口显式保留 `mode/model/revision/loaded` 四个非秘密字段，不透传模型本地路径、凭据或原始诊断。加载值只接受真正的布尔值，缺失/异常保留未知。
- GET增加 `Cache-Control: private, no-store`，刷新不触发模型加载、索引或生成。
- 页面区分未启用、已配置但当前进程未加载、已加载、未知状态；说明这只代表当前API进程，不能代替后台任务执行记录。
- 检索结果依据该次真实返回的 `reranking.mode` 显示执行/失败/未执行/未记录；不得由“已配置”推断“执行成功”。
- 本地检索成功后只额外刷新一次状态GET，保留结果，不追加搜索、索引或生成请求。
